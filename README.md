## 📝 Descrição do Projeto
O objetivo desta fase é criar a arquitetura de informação, o catálogo e a navegação do site utilizando exclusivamente a linguagem de marcação **HTML5 puro**. Conforme os requisitos da Fase 1, não há uso de customizações (CSS/Bootstrap) nem interatividades (JavaScript), que serão integradas na Fase 2.

---

## 🎯 Objetivos e Metas Desta Etapa

1. **Estruturação Semântica:** Uso de tags HTML5 (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`) para organizar o conteúdo de forma acessível e estruturada.
2. **Visualização de Produtos:** Apresentação de 3 categorias de produtos com fotos, descrições informativas e valores monetários.
3. **Catálogo de Serviços:** Listagem dos serviços disponíveis com descrição, valores e indicação de tele-busca.
4. **Navegação e Rodapé:** Criação de menus de navegação interna e rodapé institucional com contatos e autoria.
5. **Formulário e Ajuda:** Inclusão de página com formulário de cadastro/agendamento e página de ajuda com a descrição das funcionalidades do sistema.

---

## 🛠️ Tecnologias Utilizadas
* **HTML5 puro** (sem folhas de estilo em CSS e sem scripts JavaScript).

---

## 📂 Estrutura de Arquivos

* `index.html`: Página principal contendo o cabeçalho, catálogo de produtos por categorias, serviços e rodapé.
* `cadastro.html`: Página com formulário de cadastro de clientes e agendamento.
* `ajuda.html`: Página com a descrição detalhada das funcionalidades do sistema.
* `README.md`: Documentação com objetivos, metas e links do projeto.
